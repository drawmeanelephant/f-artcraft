# Site — strays expansion proposal

Status: draft, not posted. One leaf issue per bullet when approved;
`type:illustration` + `work:original`. See `.github/LABELS.md`.

`art/site/` holds four pieces — the ◈ brand mark, collection map, search
icon (⌕), and the verse-residue ornament. The generated site runs six
pages (index, plates, machines, pieces, guest, about). What the dir
suggests next is a small coherent finishing wave, not a big one:

- `site-404-plate` — a not-found plate for the site: the field-plate
  disc drawn empty, name line reading `NOT FILED` (or a small 404sy
  cameo, `mascots/404.404sy-mclostalot`, if a character is wanted —
  check with the site owner first; the piece must work without one).
  1000×1000 plate grammar.
- `site-about-plate` — the about page's own plate: a self-portrait of
  the studio table — a VectorCraft drawing of the drawing table,
  compass and plate disc. Meta but in-register; second line
  `DRAWN, NOT RENDERED`.
- `site-series-glyphs` — one small companion-glyph set, one glyph per
  catalog family the nav surfaces (plates / machines / pieces / guest),
  drawn as 64×64 chips in the site ornament's own vocabulary rather
  than the VirelaiOS chrome register. One piece, one sheet, uniform
  grid — the `sheet-*` convention applied to the site family.
- `site-footer-rule` — a long horizontal divider/ornament for page
  footers, siblings with verse-residue-ornament. Distinct from bank
  prompt OR-01 (production divider *set* for print pieces); this is one
  site-specific rule, footer-proportioned.
- `site-index-sigil` — optional: an index-page centerpiece seal —
  archive-door motif with the ◈ mark nested. Cut first if the index
  already has enough art.

`art/pieces/` is thinner and less coherent — self-portraits, the crest,
the brochure, Golly — so no standalone pieces wave is proposed; the only
stray worth flagging is that `ember-dusk` (V1R01) and the bunny pair
could take second-reading renditions later under the renditions rules,
but that's a renditions-leaf decision, not a site concern.

Shared rules: transparent or declared fields, warm dark ink, the second
line says what the piece is *for* (per `30-companion-plates.md`), and
each leaf lands an inbox note. Site equity is adopted by the build, so
leaf briefs should record intended usage without promising it.
