# Renditions — wave 2 expansion proposal

Status: draft, not posted. One leaf issue per row when approved;
`type:illustration` + `work:variation` (each names its approved base
native). See `.github/LABELS.md` and `.github/MODEL-ROUTING.md`.

A rendition is a second reading: same subject, same disc and caption
stack, a different idiom, hour, or pose — bumps `V`, resets `R`, leaves
the base revision untouched (`prompts/series/20-field-plates.md`).
Shipped idioms with in-repo lessons:

- **Psychedelic poster** — axolotl V3, jaguar V2. Lessons:
  letter-by-letter arc over envelope warp; never close a bust on a
  horizontal edge (`inbox/…-axolotl-psychedelic-review.md`,
  `…-jaguar-psychedelic-review.md`).
- **Tattoo flash** — red-eyed-tree-frog V2. Lesson: grips read via pads
  straddling the perch; Phosphate for banner lettering
  (`inbox/…-red-eyed-tree-frog-tattoo-flash-review.md`).
- **Spot-flat (GLM-Flash idiom)** — fennec-fox V2R00–R05. Grammar fixed;
  silhouette carries the species; no gradients by design.
- **Second-reading V2** — aye-aye, binturong, monarch, pangolin, saiga,
  windsor-chair, city-taxi: same plate grammar, different hour/light/
  composition.

Wave 2 proposes twelve leaves across those proven idioms plus two new
pilots (stained glass, deco poster), each flagged and capped — a pilot
idiom gets one leaf and independent proof inspection before it becomes
a series.

Rules carried forward:

- Pilot idioms (stained glass, deco poster) are budgeted: one leaf each
  (nautilus, steam-locomotive); atlas-moth/biplane wait on pilot review.
- Same caption stack, same disc geometry — rendition is idiom change,
  not format change. Second line unchanged from the base plate.
- Never overwrite the base native; driver named for the revision
  (`draw_<slug>_v2r00.py` per established convention).
- Psychedelic leaves inherit the two shipped lessons (arc lettering, no
  flat-bottomed busts); flash leaves inherit the straddle-grip lesson.
- Every leaf lands a `prompts/inbox/` review note; a pilot note should
  say whether the idiom earns a series entry.
