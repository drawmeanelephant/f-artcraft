# Necropolis — wave 2 expansion proposal: the Protocols Plot

Status: draft, not posted. One leaf issue per row when approved;
`type:illustration` + `work:original`. See `.github/LABELS.md`.

Necropolis-plate grammar (as shipped in wave 1): 1000×1000, gradient disc
centred 500,460 r≈420, name ~54–58pt at y≈930, an epitaph second line
~22–24pt tracked at y≈968. Memorial register: artifact-as-gravestone at
dawn, folded sod, mist, one small carved marker — arch, tender, never
mocking the dead (the `rk-init` "NON-DESTRUCTIVE" register). Drivers in
`work/necropolis/`.

Wave 1 filled the first terrace — rotkeeper's `/bones/` corpus, twenty-four
`rc-*.sh` script headstones, plot complete. Wave 2 opens a second terrace:
**the Protocols Plot**, memorials for dead protocols, dead formats and dead
media. The artifact itself is the headstone; the epitaph names what it did.

| slug | epithet | the marker's job |
| --- | --- | --- |
| `gopher` | THE BURROW BEFORE THE WEB | A burrow-shaped stone, a branching menu carved where the epitaph would go |
| `telnet` | THE OPEN WIRE | A glass terminal stone, 8-bit green, one session line still faintly lit |
| `ftp` | THE ANONYMOUS DROP | A drop-box marker, slot worn smooth, `ANONYMOUS` lettered small |
| `usenet` | THE INFINITE CONVERSATION | A post stone with threading ribbons unspooling down its face |
| `irc` | THE CHANNELS THAT QUIETENED | A channel stone, the nick list weathered to unreadable |
| `dial-up` | THE HANDSHAKE SONG | A handset-shaped marker; the handshake drawn as a line of staff notation |
| `guestbook` | SIGN MY GUESTBOOK | A ledger-stone left open for signatures nobody will add |
| `webring` | NEXT SITE → | A ring of small stone tiles, each pointing politely at the next |
| `cd-rom` | THE SILVER ORBIT | A silver disc set into the sod like a small buried moon |
| `zip-disk` | THE CLICK OF DOOM | A square cartridge marker with one deliberate hairline crack |
| `flash-player` | THE PLUGIN STAGE | An empty stage-stone, plug silhouette planted where the player stood |
| `crt` | THE WARM GLASS | A deep glass screen stone, face curved, phosphor afterglow dying down |

Held in reserve: `geocities` · `altavista` · `hit-counter` · `napster` ·
`perl-cgi`.

Watch-items:

- Slug scheme: wave 1's `rk-` prefix denoted the rotkeeper corpus. The
  Protocols Plot uses plain slugs above; if maintainers want the corpus
  marked, `np-` is the natural prefix.
- **Annex overlap:** the mascots wave-2 Cold Storage Annex (`701`–`712`)
  already wakes a floppy, a fax unit and a thermal page as *spirits*.
  This terrace deliberately skips floppy/fax/mimeograph subjects — the
  Annex keeps the ghost, the necropolis keeps the stone — and the same
  subject should not ship in both registers.
- Real product names in captions follow the commemoratives precedent;
  no brand logos drawn on the stones.
- `irc` and `cd-rom` are only mostly dead; the register is mourning a
  dominant era, and the leaf briefs should say that rather than claim
  extinction.
