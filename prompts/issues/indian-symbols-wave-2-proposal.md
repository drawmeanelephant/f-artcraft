# Indian symbols — wave 2 expansion proposal: the deeper field

Status: draft, not posted. One leaf issue per row when approved;
`type:illustration` + `work:original`. See `.github/LABELS.md`.

Yantra-plate grammar (`prompts/series/40-orient.md`): 1000×1000, gradient
disc centred 500,460 r≈420, one symbol per plate on a deep field in gold
geometry, name ~54–58pt at y≈930, second line ~22–24pt at y≈970 carrying
the native-script form and an epithet (the `om` precedent: `ॐ · THE
PRIMORDIAL SOUND`), vermilion chop top-right. Drivers in
`work/indian-symbols/`.

Wave 1 shipped six: om · mandala · lotus · peacock · kalash · rangoli.
Wave 2 widens the vocabulary to the objects and emblems that carry the
same symbolic weight. Slugs checked against `art/indian-symbols/` and
open/closed issues on 2026-10-25; none collide.

| slug | the plate's job |
| --- | --- |
| `sri-yantra` | Nine interlocking triangles around the bindu — the series' purest geometry piece; symmetry is the whole drawing |
| `diya` | One ghee lamp: clay cup, oil meniscus, a steady flame doing the lighting it signifies |
| `shankha` | The conch: spiral whorl, nacre sheen, the lip catching light |
| `trishul` | The trident rising from a small damaru rest; three blades, one shaft, heraldic stillness |
| `konark-wheel` | A temple chariot wheel in carved stone — spokes, hub, wear; explicitly stone, never a flag device |
| `veena` | The double-gourd resonator and fretted neck in profile; strings ≥3pt |
| `paisley` | The mango motif: one large curling teardrop carrying an interior vine of smaller ones |
| `gaja` | The royal elephant head front-on, caparisoned — the `peacock` precedent: heraldic animal, not a portrait |
| `banyan` | The many-rooted tree: canopy mass above, aerial prop roots reaching the floor chord |
| `torana` | Mango-leaf and marigold garland strung across a doorway arch; the sag curve is the composition |
| `ghanta` | The temple bell: bronze body, visible clapper, lathe rings in gradient |
| `deepa-stambha` | A lamp pillar with tiered niches, each niche holding one small flame |

Held in reserve: `mehndi-hand` · `rudraksha` · `jasmine-garland` · `tulsi`.

Watch-items:

- Symbols and objects, no deities in scene — same rule as the festival
  seals. `gaja` follows the `peacock` precedent (heraldic emblem), not a
  deity vehicle.
- `kolam` is deliberately absent: too near the shipped `rangoli`. If a
  reviewer wants it, it needs its own justification and a distinct grammar.
- `konark-wheel` must read carved stone on a temple, warm grey-ochre — the
  moment it reads flag-blue or centred-white it has failed the
  no-political-symbols rule.
- Devanagari second lines need a font check before drawing; the `om` and
  `diwali` plates established the pattern.
