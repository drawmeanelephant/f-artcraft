About this site

Every piece was drawn live inside VectorCraft over its MCP server — the driving scripts live in work/ in the repo. Nothing is raster-edited: the .vectorcraft natives are the source of truth, the SVGs are the public viewable form, and the PNGs shown here are the @2x proof renders (lettering is Virelai Sans, so the proofs are the faithful display).

Revisions are immutable: <slug>-V<V>R<RR>. V is the interpretation, R the revision inside it — a refinement bumps R, a redesign bumps V. Previous revision files are read-only; a bad revision is fixed by the next one, never edited in place.

The site is dogfooded: docs/gen_data.py scans the repo, the docs/src/*.knap templates plus the generated JSON render through dogbed (k4o → Textile → oliver → HTML) via docs/build.sh, and GitHub Actions deploys docs/site/ to GitHub Pages. The HTML is generated and committed — a CI job fails if it goes stale.
