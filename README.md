# f-artcraft

Vector art, prompts, and the round-robin loop — drawn live in VectorCraft by
Fart Knocker for drawmeanelephant. For giggles, but with commit history.

## The loop

**Prompt → build → export PDF/PNG proof → written analysis → fold the analysis
into the next prompt → next round.** A prompt is done when its piece survives
its own critique. The editable prompt bank and protocol live in
[prompts/](prompts/README.md); [PROMPTS.md](PROMPTS.md) is a periodically
compiled reading copy. Art tasks add independent notes instead of editing
the shared master; a consolidation pass folds those notes back in.
New theme lists and issue-ready drafts live in `prompts/themes/` and
`prompts/issues/`. The baseline critique of the work so far is
[ANALYSIS-ROUND-0.md](ANALYSIS-ROUND-0.md).

House rules: gradients and translucent shading, never flat fills; check proof
edges before calling anything finished; lettering in Virelai Sans; ornaments
from the Virelai Mascots glyphs. Guest and correspondent work — other agents,
people who don't natively draw, paint and mixed-media artists — is received
with appreciation, not critique; the red pen is for in-house rounds only.

## Working the queue

Check existing art, issues and open PRs, then claim one leaf issue before
drawing. The `claimed` label makes busy work visible; a verified per-worker
comment/token distinguishes agents sharing a GitHub account. Keep the claim
through review, or stop and release it with preserved-work handoff notes.
See [the claim workflow](.github/CLAIMS.md) for the helper commands and
safe adoption by already-running workers.

## Illustration styles

The repo carries several drawing grammars. Each has its own canvas, paint
rules, type, and reference pieces — see [STYLES.md](STYLES.md) for the full
survey. In short:

| Style | Where | Defining traits |
|---|---|---|
| **House field plate** | `art/animals/`, `art/insects/`, `art/furniture/`, `art/vehicles/` | 1000×1000, gradient disc (500,460 r420), gradients + translucent shading, never flat fills, warm dark ink, Virelai Sans |
| **Spot-flat (GLM-Flash)** | `test/glm-flash/`, `art/animals/fennec-fox/V2R00` | Flat silhouettes, spot-circle hub, minimal face (paper ring + vermilion dot), no gradients/outlines/translucency (deliberate break of house rule #1) |
| **Guest work** | `art/guest/` | Freebuff's DeepSeek whale in six styles (flat, sticker, neon, doodle, sunset, pixel) + dusk poster — appreciation, not critique |
| **Orient series** | `art/zodiac/`, `art/holidays/`, `art/indian-symbols/` | Plate grammar + vermilion seal chop, element palettes, cultural guardrails (no flags/maps/political symbols) |
| **Companion plates** | `art/mascots/`, `art/lorelog/`, `art/poetry/`, `art/site/` | Same disc/caption stack, second line is role/epithet not spec |
| **Named pieces** | `art/pieces/` | One-offs — Fart Knocker portrait (style anchor), crest, bunny set, golly, ember-dusk, empathegy |
| **VirelaiOS assets** | `art/virelai/`, `virelai/` | Chrome register (flat, 1px borders) vs asset register (cel shading, thick outlines); icons, cursors, mascots, wallpapers, spots, filetypes, brand |

Cross-cutting house rules (apply unless a style opts out by design): gradients
and translucent shading, never flat fills; check proof edges before done;
lettering in Virelai Sans; ornaments from the Virelai Mascots glyphs; never
overwrite a piece — revisions are `<slug>-V<V>R<RR>`.

## What's here

- **art/** — the canonical home of every piece, versioned `<slug>-V<V>R<RR>`
  (native + `.svg` + `@2x.png`), always `art/<series>/<slug>/`. Series work —
  `art/animals/`, `art/insects/`, `art/mascots/`, `art/vehicles/`,
  `art/furniture/`, the Orient sets — sits beside `art/pieces/` (the named
  works: Fart Knocker self-portrait and crest, the Filed & Forgotten set,
  Ember dusk, Empathegy), `art/muse/` (Jolly, the regular Muse mascot:
  portrait, waving, and a meeting with a very small Fart Knocker) and
  `art/guest/` (work from other agents: Freebuff's DeepSeek whale in six
  styles, and a dusk poster).
- **test/** — throwaway experiments that don't touch the house grammar or
  the gallery scan. `test/glm-flash/` is the spot-flat style exploration
  (mid-century spot circle, flat silhouettes, no gradients).
- **virelai/** — VirelaiOS interface art and design docs (icons, cursors,
  mascot poses, wallpapers, spots, filetypes, brand), with its own
  conventions in `virelai/README.md` and taste rules in
  `virelai/notes/style-bible.md`.
- **work/** — the scripts that drove VectorCraft's MCP server. Drawing
  scripts live next to their subject: `work/<series>/` mirrors `art/`,
  `work/tools/` holds shared scratch utilities. `vc.py`, `mcp_client.py`
  and `check_rim.py` at the root are the shared harness.

## The site

[https://drawmeanelephant.github.io/f-artcraft/](https://drawmeanelephant.github.io/f-artcraft/)
— the gallery, generated by dogbed: `docs/gen_data.py` scans the artwork into
`docs/data/*.json`, `docs/src/*.knap` renders through `docs/build.sh` into
`docs/site/`, and the `pages` workflow rebuilds and deploys it to GitHub
Pages on every merge to main. Generated output is never committed — new
art reaches the site automatically; the `docs-build` check just proves
the render still runs.

## What's not here

PDF proofs and scratch renders stay local in `work/out/`. Revision
deliverables committed with the piece are the editable `.vectorcraft`
native (JSON), the `.svg`, the `@2x.png` and the driving script.
Nothing here is a promise. Bad manners, good engineering.
